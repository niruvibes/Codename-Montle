# Operation: Chronomancy
Welcome to Chronos, a simple planning application which will sort out all your activites into a planner by priority. Chronos will also add breaks into your plan so you arent working 24/7.<br>

## Features Brainstorm
Operation: Chronomancy

list all items due - Alongside type (Assignment, Homework and/or Interested)
Sort by Duedate or Assignment

Generate a random timetable with a few of the most value type items (Ass or Duedate)
Holiday mode, entire 12 hour plan has 3 hours of pause*
The schedule generated has the dedicated time periods on the left hand side
Also includes Lax time periods for meals, exercise, chores and shower. 
Can include additional content that includes random tasks appointed by me. at completely random time frames
e.g. Walk around your house. Do 30 push ups.
A timer on each subject at the bottom, (Use a combination key to pause the timer)

Pause moves everything on the schedule back for the duration of the pause (Gaming y'know)
Inbetween every task is a short break such as go get food/drink water/ standup message (Intermission)

Saves every 10 minutes
Saves via pickling the class object
